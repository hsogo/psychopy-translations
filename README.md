# psychopy-translations

Welcome to the PsychoPy Translations repo! This is a central repository to store/update/maintain all translation strings needed for PsychoPy, irrespective of where that string is used; in the library, in the app, or in the (official) plugins.

We hope that, with the improvements in AI agents, the bulk of translation work can be accomplished by AI but if you're happy to help improve some translated PsychoPy labels then this is the place to be!
